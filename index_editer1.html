검색엔진 목록 편집

번호를 드래그하거나 ↑↓ 버튼으로 순서를 바꾸고, 이름·주소를 바로 고치면 자동 저장됩니다. 검색 URL 뒤에 검색어가 붙어서 열립니다 (비우면 항상 홈으로). 공백→ 칸에 문자를 넣으면 검색어의 띄어쓰기가 그 문자로 바뀝니다 (예: -). 노란 특수 표시 엔진은 이 페이지 전용 기능(차트 매핑·자동완성 등)으로 동작하므로 이름·순서만 바꾸는 것을 권장합니다.

자주쓰는 검색어

여기에 저장한 검색어는 검색창을 눌렀을 때 목록으로 나타나고, 누르면 입력창에 채워집니다. 번호를 드래그하거나 ↑↓ 버튼으로 순서를 바꾸고, 내용을 바로 고치면 자동 저장됩니다. 내보내기/가져오기(JSON)와 편집판 HTML 저장에도 검색엔진과 함께 포함됩니다.

코드 · 완성 파일 저장

편집판 HTML — 지금의 엔진 목록과 자주쓰는 검색어가 기본값으로 박힌 index 파일을 내려받습니다. 편집판에서는 이 코드 버튼과 기본값 복원 버튼이 숨겨지고, ✎ 편집·내보내기/가져오기는 계속 사용할 수 있습니다. 내려받은 파일을 index.html로 이름을 바꿔 GitHub 저장소에 올리면 배포됩니다.
